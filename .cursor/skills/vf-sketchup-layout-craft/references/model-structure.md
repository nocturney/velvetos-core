# SketchUp model structure

- Establish units and origin/reference axes before detailed placement.
- Keep logical objects isolated as groups/components so edits do not unintentionally merge raw geometry.
- Use components for repeated objects that should share definition changes; use unique instances when they must diverge.
- Name important groups/components by role, not by creation order.
- Keep real-world dimensions source-backed and check critical clearances with measurement tools.
- Avoid excessive hidden duplicate geometry. Purge only after confirming unused content is truly disposable.
- Separate conceptual placeholders from verified equipment/furniture dimensions.
