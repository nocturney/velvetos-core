# Tool routing

- SketchUp 2026: spatial model, groups/components, scenes, tags, measurements and source geometry.
- LayOut: associative viewports, sheets, dimensions, labels, title blocks and drawing-set export.
- Ruby automation: use only through a separately accepted local bridge/CLI/plugin surface. The presence of the Ruby API does not by itself prove VelvetOS has a live automation path.
- Manufacturing-critical parts should route back to `vf-cad-design-craft` / `vf-3d-router` when a true engineering master is required.
