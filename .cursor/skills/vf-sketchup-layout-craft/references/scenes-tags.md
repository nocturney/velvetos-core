# Scenes and tags

- Use tags to control visibility of logical grouped/component content; avoid using tag state as a substitute for object structure.
- Use scenes for meaningful documented viewpoints/states such as plan, elevation, detail, presentation or installation sequence.
- Keep camera/style/tag state intentional per scene so LayOut viewports remain predictable.
- Avoid manual viewport camera drift in LayOut when the drawing is expected to remain scene-driven.
- When a referenced model changes, re-check every affected scene/view used in documentation.
