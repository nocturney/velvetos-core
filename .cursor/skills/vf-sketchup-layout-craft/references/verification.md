# SketchUp/LayOut verification

1. Confirm units and at least one known real-world dimension.
2. Check component/group hierarchy and accidental raw-geometry merges.
3. Review documented scenes and tag visibility.
4. In LayOut, verify every model/image reference is current or intentionally frozen.
5. Check viewport scale, crop and rendered style.
6. Re-check dimensions/callouts after any model-reference update.
7. Export the exact drawing set and inspect every page for clipping, missing labels or stale views.
