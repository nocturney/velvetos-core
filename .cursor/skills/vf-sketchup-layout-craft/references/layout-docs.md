# LayOut documentation

- Insert SketchUp models as references and preserve the reference relationship for updateable documentation.
- Use model scenes as the basis for viewports; set drawing scale explicitly where measured documentation is required.
- Keep dimensions associated with the intended model geometry/view and re-check them after reference updates.
- Use title blocks, page numbering and revision information consistently across a drawing set.
- Keep line weights, vector/raster/hybrid rendering mode and label hierarchy appropriate to the drawing purpose.
- Current LayOut supports checking out-of-date model references in Document Setup and updating or relinking them; make reference freshness a mandatory pre-export check.
- Export the full set and review page order, viewport crop, labels and dimensions in the resulting PDF/image set.
