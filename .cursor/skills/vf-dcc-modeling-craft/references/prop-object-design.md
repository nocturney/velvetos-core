# Prop and object design craft

Use for grounded products, furniture, tools, containers, electronics and hero objects where generic hard-surface or sci-fi language would be wrong.

- Set real-world scale and protected interfaces before detail.
- Make the silhouette and primary proportions readable before seams, bevels, fasteners or surface noise.
- Build believable part logic: separate pieces where assembly, material, motion or service access actually changes.
- Use controls, handles, grips, hinges, sockets and pivots as functional signifiers rather than decoration.
- Keep everyday objects restrained. Do not add panel lines, vents, bolts or grooves just to make the model feel 'designed'.
- Establish a detail hierarchy: primary form, secondary construction, then local manufacturing/wear cues.
- Put wear where contact, handling, abrasion, heat or dirt plausibly occurs; protected faces should not receive uniform procedural damage.
- Review the object at intended camera distance and thumbnail size; close-up detail must not compensate for a weak overall read.
- For printable or mechanical objects, preserve the engineering master and protected dimensions while the DCC layer explores cosmetic form.
