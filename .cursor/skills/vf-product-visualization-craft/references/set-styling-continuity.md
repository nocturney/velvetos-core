# Set styling and continuity

- Use background, floor and props to support scale, mood and hierarchy without competing with the product.
- Never use a prop that implies unverified compatibility, package contents, safety, capability or dimensions.
- Keep brand-critical color and labels stable across the shot family.
- Record intentional changes in camera, light, surface, prop or background between variants.
- For turntables, keep exposure, world orientation and product center stable unless the shot brief says otherwise.
- Use restraint: absence of set dressing is preferable to a visually rich but misleading context.
