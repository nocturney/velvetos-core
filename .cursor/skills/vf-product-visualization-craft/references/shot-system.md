# Product shot system

- Start from the communication job: diagnostic, catalog, hero, detail, comparison, turntable, or campaign context.
- Write a one-line purpose for every planned view and remove shots that do not reveal distinct information.
- Keep a neutral diagnostic frame as the accepted comparison state before beauty styling.
- Define protected source elements before making visual choices: geometry, materials, labels, colorway and scale.
- For a shot family, declare which camera, light, background and crop attributes are locked versus intentionally varied.
- Use a small set of repeatable view families rather than ad-hoc camera proliferation.
- Bind critique notes to the exact source revision and render output.
