# Print PDF output QA

1. Export using the provider's supplied preset/standard when available.
2. Confirm page size, trim/bleed boxes and requested printer marks.
3. Confirm fonts are embedded/subset as expected and no missing-font substitution occurred.
4. Check image effective resolution against provider requirements rather than a universal DPI rule.
5. Verify output intent/profile and spot/process handling.
6. Re-open the PDF in Acrobat or another reliable inspector.
7. Run output/separation preview and inspect representative pages plus high-risk transparency/overprint areas.
8. Confirm page count/order, crop, bleed continuation and no accidental nonprinting/hidden content.
9. Preserve the editable source separately from the delivery PDF.
