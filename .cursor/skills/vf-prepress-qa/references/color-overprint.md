# Color, separations and overprint

- Resolve the provider's expected process/spot-color policy and output profile before conversion.
- Use Separations/Output Preview to inspect process plates, spot inks and overprint behavior in the exact output.
- Check unintended spot colors, duplicate spot names, registration color misuse and objects that disappear/change when overprint is simulated.
- Treat overprint as an intentional production setting. Adobe documentation recommends checking with the print provider before applying manual overprint choices.
- Inspect total ink coverage against the provider/profile requirement; generic ranges are guidance only, not authority.
- On-screen separation preview cannot prove trapping, halftone or final press behavior. Escalate to provider proof/specification when those matter.
