# Preflight

- Check missing/modified links, missing fonts, overset text, low-resolution assets, hidden/nonprinting content that matters, unexpected color spaces and document-size/bleed setup.
- Use an embedded or provider-specific preflight profile when one exists.
- For multi-document books/publications, preflight the whole output set with one consistent profile unless the provider specifies otherwise.
- Resolve errors in the source document before packaging/export whenever possible.
- Keep linked assets current; a print PDF exported from stale links is not production-ready.
- When packaging a source document for a printer/collaborator, include only assets/fonts allowed by license and record omissions.
