# DFM, GD&T and functional datums

Use function-first reasoning. Standards/provider guidance can inform the method, but no copied paywalled standard text or provider-specific number becomes universal Velvet policy.

- Start from how the part is located, loaded, assembled, inspected and manufactured. Choose datum features that reproduce those functional constraints rather than convenient drawing edges.
- Describe the degrees of freedom each datum relationship is intended to constrain.
- Keep a tolerance chain tied to the functional requirement it protects; avoid scattering independent tolerances without a stack rationale.
- Separate design requirement, manufacturing capability and inspection method. A drawing tolerance that cannot be produced or measured reliably is unresolved.
- Use process-aware DFM: machining, molding, sheet, additive and post-processing impose different access, wall, draft, radius, support and inspection concerns.
- Treat provider design guides as capability/context evidence, not standards. Reverify any wall, draft, kerf, radius or tolerance number for the actual process/material/provider.
- Preserve datum/interface intent through parametric perturbation tests and after export.
- If GD&T notation is required, use the applicable current standard/project convention through the owning engineering authority; this craft reference does not reproduce normative tables.
