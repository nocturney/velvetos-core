# Motion direction

Use for art-directed motion graphics, transitions, title animation and animated visual systems across After Effects, Resolve/Fusion, Premiere, HyperFrames or DCC animation.

- Start from emotional intent and the micro-story: setup, action, resolution. Motion must communicate something before it decorates.
- Define the motion language before keyframing: motion personality, base timing unit, easing family, transition family, stagger rhythm and intensity. Keep those choices consistent unless a deliberate contrast is part of the concept.
- Separate motion into primary, secondary and ambient layers. Primary carries the viewer's attention; secondary supports it; ambient gives life without competing.
- Use the minimum moving properties necessary. Too many simultaneous changes reduce clarity and make motion feel template-driven.
- Entrances should decelerate into place; exits usually accelerate away; on-screen travel should ease at both ends unless the physical idea requires otherwise.
- Match perceived weight: heavy objects settle more slowly and with less overshoot; elastic/light objects can react faster and carry more follow-through.
- Coordinate multi-element motion through hierarchy and stagger rather than making everything start together.
- Use anticipation, follow-through, arcs and secondary motion only when they fit the material/object/story; never apply them as a universal preset.
- Keep motion paths, direction and timing aligned with the composition and edit so the eye is led to the intended target.
- Run a restraint pass after the first successful animation: remove motion that does not carry meaning, hierarchy or useful physical response.
- Run a consistency audit across shots/scenes against the declared motion language; note intentional exceptions instead of letting them drift.
- Review at real playback speed. If motion attracts attention after its message is understood, reduce amplitude, duration or layers.
