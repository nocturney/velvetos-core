# VFX technical-check compatibility pointer

This file remains for compatibility with older references. VFX technical checking is now owned by `vf-vfx-compositing-craft`, especially its `shot-qc.md`, `shot-setup-plate-lens.md`, `roto-key-mattes.md`, `tracking-matchmove.md` and `integration-finishing.md`.
