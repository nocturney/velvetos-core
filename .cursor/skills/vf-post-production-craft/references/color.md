# Color craft

- Resolve color management/input interpretation before grading. Do not grade around an incorrectly interpreted source.
- Correct exposure, white balance and major channel problems before building a creative look.
- Use scopes for objective signal information while judging the image visually on the intended display path.
- Match shots for exposure, color balance and contrast before adding scene-wide style.
- Keep skin/product/reference colors tied to real source intent when truth matters.
- Separate technical transforms, primary balance, shot matching, look development and output transforms so failures can be diagnosed.
- Check highlights, shadows and saturation for clipping/compression introduced by the grade or output transform.
- Apply broadcast/legal limits only when the destination specification requires them.
