# Post-production composition boundary

Use this reference for editorial/motion composition: titles, graphic layers, simple masks, transitions and 2D layout that belong to the edit or motion piece. Plate VFX, roto/key, tracking/matchmove, lens-distortion workflows, render-pass reconstruction and CG integration route to `vf-vfx-compositing-craft`.

- Build motion composition from source truth outward and keep major layer/mask/transform stages inspectable.
- Preserve exact copy, typography hierarchy and Hebrew/RTL behavior through animation and export.
- Keep alpha/premultiplication and color-space assumptions explicit when filtering or merging layers.
- Prefer procedural/repeatable links for motion relationships when they remain maintainable.
- Inspect first, middle, last and timing/motion stress frames.
- If the task depends on plate tracking, difficult mattes, lens geometry, grain/defocus matching or CG integration, stop and apply the VFX specialist rather than stretching this post skill into a second VFX owner.
