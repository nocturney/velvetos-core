# Slicer routing notes

- OrcaSlicer: primary craft reference for current calibration-led workflows and the existing VelvetOS dynamic slicer path when selected.
- PrusaSlicer: use native profiles/features when it is the resolved slicer; preserve profile provenance and re-check after updates.
- Bambu Studio: use vendor-specific profiles/calibration where the relevant machine ecosystem requires it; this skill still does not grant printer-control authority.
- ElegooSlicer and Flash Studio: reference/vendor-profile sources only unless the separate fabrication workstream explicitly promotes them to production use.
