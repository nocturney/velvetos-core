# BOM structure

- Give each part/item a stable identifier and revision when the source provides one.
- Track parent/assembly relationship, level, quantity-per, unit of measure and make/buy status separately.
- Distinguish reference/designator or drawing position from the stable part identifier.
- Preserve source description/material/process fields without rewriting facts for convenience.
- Keep optional/alternate/configuration parts explicit rather than blending them into one total.
- Reconcile duplicate IDs, missing IDs and zero/blank quantities against the source before rollup.
