# Costing model

- Treat unit purchase/material price as an input with source/date/currency, not a constant hidden in a formula.
- Convert material consumption into purchased quantity with explicit yield/scrap assumptions only when those assumptions are provided or evidenced.
- Separate setup cost from variable run cost where volume changes matter.
- Separate direct labor, machine/process, subcontract, packaging, logistics, fees/tax and overhead so inclusion is auditable.
- Show extended cost = validated quantity basis x validated unit/rate logic, with unit compatibility checked.
- For scenario analysis, put alternate assumptions in dedicated scenario inputs and keep the base case intact.
