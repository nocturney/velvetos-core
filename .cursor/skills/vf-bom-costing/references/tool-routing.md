# Tool routing

- Excel: preferred for formula-rich BOM/cost models, tables, lookups, pivots and scenario analysis when the source is an Excel workbook.
- Google Sheets: use when the source of truth is a shared Sheet and the connected Drive/Sheets workflow is authoritative.
- CSV/TSV: treat as data interchange; formulas, formatting, units and metadata may need a separate explicit model.
- Keep accounting/ERP or supplier systems authoritative for facts they own; this skill does not manufacture missing commercial data.
