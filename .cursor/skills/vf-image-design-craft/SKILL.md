# Velvet Image + Vector Design Craft

Use the best existing local editor for the artifact while preserving editability, source truth and downstream requirements.

## Workflow

1. Resolve artifact type, source assets, required dimensions, color/output context and whether geometry/product identity must remain exact.
2. Read only the needed references: `moodboard-art-direction.md`, `raster.md`, `vector.md`, `vector-identity.md`, `mixed-media-editorial.md`, `composition.md`, `graphic-systems.md`, `typography-layout-qa.md`, `export-qa.md`, `tool-routing.md`.
3. Preserve a recoverable source/master before destructive operations.
4. Work non-destructively where the host supports it and where editability has value.
5. Inspect the exact export at intended size/use before delivery. If the destination is physical print or a print provider, also apply `.cursor/skills/vf-prepress-qa/SKILL.md` to the final print artifact.

## Core rules

- Keep masks, adjustments, transforms and reusable source objects editable until flattening/export is justified.
- Separate image correction from content invention. Do not generate missing evidence-bearing product detail.
- Keep logos/wordmarks from approved assets; never ask a generative system to recreate an exact brand mark when the real asset exists or is required.
- Use vector geometry for shapes/type that benefit from scale-independent output.
- Apply typography and exact Hebrew/RTL text deterministically when correctness matters.

## Hard stops

- Do not grant publication authority.
- Do not replace a verified product/source image with a synthetic lookalike while representing it as the real product.
- Do not rasterize/flatten the only editable master without a requirement.
- Do not invent font/image/license rights.

## Completion contract

Report `source_preserved`, `edit_structure_checked`, `visual_checked`, `text_checked`, `export_checked`, `rights_known` separately.
