# Moodboard and art direction

Use before execution when a project needs a visual direction rather than an immediate pixel-level edit.

- Write the emotional target before collecting references. Describe how the work should feel, not only what category it belongs to.
- Source broadly, then cut ruthlessly to a small board of references that each contribute a unique idea. Do not let quantity substitute for direction.
- Cover the visual dimensions that matter to the project: color/value, material/texture, light, composition/space, typography and human presence when relevant.
- Tag every reference as INSPIRATION or EXECUTION. Inspiration may define mood or principle without implying literal reproduction.
- Avoid letting one brand/campaign dominate the board; the goal is a direction, not a disguised copy target.
- Build an anti-board with several explicit directions to avoid and a short reason for each. Negative constraints prevent generic fallback later.
- Translate the board into a compact art-direction statement that another designer, photographer, 3D artist or motion designer can act on without seeing the full board.
- Extract actionable principles such as palette range, lighting softness, density/whitespace, material honesty, camera stance and typography behavior.
- Preserve source links/rights notes separately. A visual reference is not a license to reuse production imagery or exact protected artwork.
- Recheck later outputs against the emotional target and anti-board, not only against one attractive reference image.
