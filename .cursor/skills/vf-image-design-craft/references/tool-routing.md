# Tool routing

Execution remains on accepted local adapters and normal vendor applications.

- Photoshop: raster cleanup, retouching, compositing, masks and pixel-level finishing; use the existing first-party bridge when automation is required.
- Illustrator: vector construction, exact paths/type/graphics and scalable export; use the accepted existing adapter.
- Affinity: use native raster/vector/layout capability when it is the source application or best fit; do not claim automation unless a current accepted integration exists.
- CorelDRAW: use for vector/technical artwork and Corel-native sources; preserve editable source and export independently.
- Corel PHOTO-PAINT: use for Corel-native raster work and image cleanup.
- Do not add another editor runtime merely because an upstream skill or MCP exists.
