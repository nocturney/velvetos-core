# Mixed-media graphic and editorial design

Use for Affinity, InDesign, CorelDRAW or similar work that combines vector, raster, photography, typography and page layout.

- Decide the information hierarchy and grid before decorating individual elements.
- Use one coherent spacing/alignment system across vector, image and text layers; mixed media should feel intentional rather than collaged by accident.
- Keep vector shapes/type editable and raster adjustments non-destructive while the design is still changing.
- Establish page/section rhythm through repeated anchors, controlled variation and deliberate whitespace rather than filling every region.
- Treat typography as a system: roles, scale, weight, measure, leading, tracking and contrast must support the content hierarchy.
- For editorial layouts, control the relationship between image crop, caption, body, headline and page edges across a sequence, not just on one page.
- Use master pages/templates/styles/components when repetition should remain synchronized.
- Preserve linked-source provenance and detect missing/modified links before export where the host supports it.
- Keep brand/logo assets exact; experimentation belongs around the asset, not inside an unapproved redraw.
- Hand print-bound output to the existing prepress skill for bleed, boxes, separations, fonts and provider-specific PDF requirements.
