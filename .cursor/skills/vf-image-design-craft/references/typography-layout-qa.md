# Typography and layout QA

Use for editorial, brand, poster, interface-like graphics and mixed-media layouts where polish depends on spacing and hierarchy.

- Establish a visual thesis and hierarchy before decorative styling. One dominant event should lead; supporting elements should not compete equally.
- Use grid/alignment as structure, not as dogma. Break it only when the break improves hierarchy or meaning.
- Judge optical alignment in addition to bounding-box alignment, especially for circles, triangles, punctuation, caps and asymmetric marks.
- Check line length, leading, paragraph spacing, widows/orphans and rag shape at the actual intended size.
- Build type hierarchy through a controlled combination of scale, weight, spacing, placement and contrast rather than many unrelated fonts/styles.
- Test grayscale/blur and thumbnail views to reveal weak hierarchy that color or detail may be hiding.
- Check tiny/reduced output for counters, hairlines, spacing and icon/wordmark survival.
- Preserve exact copy, Hebrew/RTL order, punctuation and numerals through export.
- Avoid copying a named design system's brand identity; borrow only general layout/QA principles when licensed/appropriate.
- Keep an anti-reference or explicit "avoid" list when the project risks converging on generic template aesthetics.

Final polish is a separate pass after structure is stable; do not fix weak hierarchy with ornamental effects.
