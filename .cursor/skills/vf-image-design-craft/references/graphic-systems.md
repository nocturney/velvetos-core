# Graphic systems

- Build a small explicit system for hierarchy, spacing, alignment, type roles, shape language and reusable tokens before decorating individual screens/artboards.
- Use consistent relationships, not copied brand aesthetics. External design systems can demonstrate structure without authorizing their colors, components, icons or identity.
- Define a type scale/role set from content needs; judge optical alignment, line length, leading and reduced-size survival.
- Prefer a limited spacing rhythm and alignment logic so exceptions are visible and intentional.
- Treat components/patterns as reusable behavior with states, not merely duplicated artwork.
- Use contrast, scale, position and whitespace to establish one dominant reading path.
- Run grayscale/blur/thumbnail checks to expose hierarchy that depends too heavily on color or detail.
- Keep exact copy, numerals, logos and RTL order as protected content through layout/export.
