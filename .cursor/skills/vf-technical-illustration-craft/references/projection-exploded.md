# Projected and exploded views

- Choose orthographic/isometric/projected presentation based on what the reader must understand.
- Preserve spatial relationships while offsetting parts in exploded views; avoid arbitrary trajectories that imply the wrong assembly order.
- Use consistent projected-plane logic for objects intended to share one technical view.
- Keep section/detail views tied to the source area they explain.
- Use line hierarchy to separate visible edges, hidden/supporting information and annotation.
- When a 3D/XVL source can remain linked, prefer updateable source relationships over manual redrawing.
