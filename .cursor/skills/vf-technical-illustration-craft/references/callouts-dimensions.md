# Callouts and dimensions

- Point leaders to unambiguous features and avoid crossing/stacking that forces the reader to trace lines unnecessarily.
- Use linked callouts/object properties when source metadata is authoritative and the tool supports it.
- Keep balloon numbering consistent with the parts list; renumber only through an explicit mapping operation.
- Use dimension types appropriate to the measurement: linear/parallel, angular, radial/diametric, segment, etc.
- Preserve dynamic/associative dimensions where useful; if a dimension becomes static, verify it again after source changes.
- Drawing scale and units must be explicit on scaled technical sheets.
