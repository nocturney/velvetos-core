# Parts and object data

- Treat part number/ID, description, quantity and revision as data, not decoration.
- Keep one mapping between source component identity and the illustration callout/balloon.
- Detect duplicate or orphaned identifiers before publishing a parts graphic.
- If source metadata is missing, mark it unresolved rather than inventing a plausible code.
- When an exploded view and BOM coexist, verify every shown serviceable/identified part against the list and vice versa.
