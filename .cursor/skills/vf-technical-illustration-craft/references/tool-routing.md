# Tool routing

- Corel DESIGNER: primary for technical vector illustration, callouts, dimensions, projected drawing cleanup and page composition when the source/workflow is Corel-native.
- XVL Studio Corel Edition: use for 3D-derived technical views, exploded arrangements and source-linked parts/metadata when available.
- Preserve CAD/3D engineering masters as read/reference sources; do not make the illustration file the new geometry authority.
- If a live automation adapter is not accepted at runtime, keep execution manual/native-app and still apply this craft/QA guidance.
