# Licensing and consent

- Record the application/runtime license, the speech model license and any voice/sample rights separately.
- `faster-whisper` is MIT-licensed software; that does not automatically grant rights to every model or audio source used with it.
- VoiceStudio's application license and the licenses of downloadable/upstream models must be checked independently.
- For a cloned/identifiable real voice, record explicit authorization and intended use scope before generation intended for external use.
- If provenance or rights are unclear, block public/commercial delivery rather than guessing.
