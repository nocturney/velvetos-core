# לוח צינור (Pipeline Board)

דפוסים מ־Twenty Opportunities, Krayin leads, Monday boards, Salesforce pipeline, Dolibarr proposals.

צינור יחיד — **אין** עמודות אנגליות מקבילות:

`פנייה → שיחה → הצעה → הדפסה → איסוף`

## עמודות

| עמודה | מתי כרטיס כאן | פק מוביל | צבע בריף |
|---|---|---|---|
| פנייה | בריף הזמנה נפתח, חסרים מסומנים | `vfconvert` | — |
| שיחה | ממתינים לתשובת לקוח / גילוי | `vfsales` | 🟡 |
| הצעה | טיוטה או הצעה פתוחה; מחיר `X ₪` עד אימות | `vfsales`+`vfcopy`+`vfcost` | 🟡 |
| הדפסה | שולם/אושר; בתור או על המכונה | `vfprod` | 🟢 / 🖨️ |
| איסוף | מוכן לאיסוף שדרות / נאסף | `vfbooks`+`vfsales` | 🟢 |

איחור (דדליין עבר בסנאפשוט) → סימון 🔴 על הכרטיס, לא עמודה שישית.

## כרטיס (שדות מינימום)

```markdown
## job/<שם-קצר>
- שלב: פנייה|שיחה|הצעה|הדפסה|איסוף
- מקור: Gmail thread id / WhatsApp (אדם) / …
- חסרים: …
- מחיר: X ₪ | <סכום מאומת + מקור>
- רישיון קובץ: #vlicense …
- תור שעות: אין ספירה | <סלייסר מאומת>
- CTA: WhatsApp 050-2517000 / איסוף שדרות
```

בלי שם מלא מיותר. בלי ₪ מומצא. בלי «שלחו DM».

## מיפוי משמות חיצוניים (לא צינור שני)

| Twenty / Salesforce / Monday | אצלנו |
|---|---|
| Lead / New | פנייה |
| Qualified / Contacted | שיחה |
| Proposal / Quote | הצעה |
| Won → Production / Job | הדפסה |
| Closed / Delivered | איסוף |

## איך מעדכנים היום (בלי אפליקציה)

1. כרטיס בתיקיית job / Drive doc לפי שם העבודה.
2. בריף בוקר (`BRIEF-SLOTS` 02–03) סופר כרטיסים **רק ממקור מאומת**.
3. UI עתידי קורא את אותם כרטיסים — לא DB מקביל.
