Privacy Policy

Velvet Factory Mail Brief is a private owner-operated application used to send operational email briefs for Velvet Factory.

Google user data

The application requests the Gmail send permission solely to send messages initiated by the Velvet Factory owner-operated workflow. It does not request permission to read, search, download, modify, or delete mailbox content.

Use and storage

OAuth credentials are used only to authenticate the Gmail API sending workflow. Credentials are kept in private secret storage and are not committed to the public source repository.

Sharing

Google user data is not sold, rented, or shared for advertising. Access is not provided to third parties except infrastructure providers required to execute the owner-operated workflow.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to nocturney@gmail.com.
