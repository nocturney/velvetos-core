# טיוטות שסוגרות שלב

## מסלול

`ליד → דרישות (#vfconvert) → הצעת מחיר (אחרי #vfcost) → אישור → תשלום (#vfbooks) → ייצור (#vfprod)`

כל טיוטה חייבת לקרוא לפעולה אחת: לשלוח מידה / לאשר בריף / לאשר סכום שאמר כריסטיאן / לקבוע איסוף בשדרות.

## טון

לא: «שלום, נשמח לעמוד לשירותך.»  
כן: משפט קצר, עברית מדוברת, בלי הבטחת מחיר ריק.

אם הלקוח משווה למוצר מדף זול — מסבירים ייצור לפי דרישה + זמן מכונה + התאמה. אפשר להציע גרסה פשוטה יותר *רק* אחרי `#vfprod`. בלי מספר ₪ בטיוטה עד שיש סכום מאומת.

## אחרי איסוף

טיוטת בקשת תמונה / המלצה / חזרה. אדם מחליט אם לשלוח.  
לא מייל ללקוח על חוב בלי הוראת ראש צוות (יש תקדים: תזכורות פנימיות בלבד).
