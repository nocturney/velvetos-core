# סיכום פגישה והכנה

מקור: `agents/10-meeting-notes-agent` + CrewAI Meeting Assistant / Prep.  
חבילות: `vfops`, `vfbriefux`.  
יומן: קריאה `Asia/Jerusalem`. יצירת אירוע רק אם ביקשו.

## הכנה (לפני שיחה)

מ־Calendar + מה שיש בצינור:

```
מתי:
נושא:
עבודות פתוחות רלוונטיות:
מה חייבים לסגור בשיחה:
מה אסור להבטיח (₪ / מועד בלי מיטה):
```

## אחרי תמלול או הודעות

רק ממה שנאמר:

```
סיכום (3–5 שורות):
החלטות:
פעולות — מי / מה / מתי אם נאמר:
חסמים:
חסר לקביעת איסוף בשדרות:
האם נופל לבריף 07:00: כן/לא
```

## אסור

- להמציא בעלים או תאריך.
- לשים שם לקוח מלא בגיט. קוד עבודה מספיק.
- לשלוח סיכום ללקוח מ־HQ. טיוטה פנימית; אדם שולח בוואטסאפ אם צריך.
