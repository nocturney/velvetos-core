# שש שכבות — מיפוי למשרד

מקור מתודולוגי: הפלייבוק שהבעלים העלה (Harness Engineering, אוגוסט 2026).  
ביצוע: קבצים שכבר חיים ב-HQ. אין מסגרת חיצונית.

`layers.json` הוא מקור האמת למכונה. כאן ההסבר.

## 1. Guides — לפני הביצוע

Feedforward. כל שורה צריכה להיות פעולה או קריטריון נצפה, לא סיסמה.

| קובץ | מה הוא מונע |
|---|---|
| `AGENTS.md` | ניחוש סביבה; כשלים שכבר תוקנו בשיחה |
| `constitution/CONSTITUTION.md` | צינור שני, מושב שישי, שליחה |
| `.cursor/rules/velvet-factory-desk.mdc` | הפעלת 273 סוכני מחסן על הדפסת שדרות |
| `packages/<name>/SKILL.md` | עבודה בלי פק / בלי מושב |

ה-ratchet: כשל → מחלקת כשל (לא סימפטום) → כלל במדריך או סנסור → בדיקה שהכשל לא חוזר. תיקון בשיחה מת עם הסשן.

## 3. Loop — תכנון, ביצוע, בדיקה, תיקון

ראה [`LOOP.md`](LOOP.md). גבול ברירת מחדל: 2 ניסיונות ואז הסלמה. הסלמה היא הצלחה אם היא חוסכת תשובה בטוחה ושגויה.

## 4. Memory — הקובץ זוכר

| שכבה | מה נשמר | איפה |
|---|---|---|
| Scratchpad | המשימה הנוכחית | `state/<id>.json` |
| Artifact | טיוטה / בריף / כריכה | הפק הרלוונטי |
| Decision | החלטת ראש צוות | `CHANGELOG.md`, `constitution/` |
| Guide | מדיניות קבועה | `AGENTS.md` — לא בזיכרון שיחה |
| Office map | איך המשרד מחובר | `vfgraft` (`MAP.md`) |
| Office query | מי מטפל במשימה | `vfmem` (`scripts/vfmem.py`) |

`vfgraft` / `vfmem` הם מפת משרד, לא checkpoint של משימה. לא מחליפים זה את זה.

מבחן שחזור: סוגרים סשן באמצע. נפתח. קוראים את ה-checkpoint. ממשיכים בלי לחזור על עבודה גמורה.

## 5. Permissions — הרתמה היא גבול האבטחה

ראה [`PERMISSIONS.md`](PERMISSIONS.md). Prompt injection באימייל / PDF / issue לא מרחיב הרשאות.

## 6. Observability — אפשר לאתר איפה נשבר

| אות | איפה |
|---|---|
| מה נבנה היום | `CHANGELOG.md` Unreleased |
| מאיפה הגיע פק | `packages/<name>/ORIGIN.md` |
| האם השולחן שלם | פלט `check-all.py` |
| חומה / אין גוף | `packages/vfresearch/sources/` |

Trip wires שכבר קיימים כסנסור: ₪ בלי `X ₪`, פק לא מוכר במפה, חוק שולחן בלי `send_message`.

## הרחבת רב-סוכן (בלי mesh)

המשרד כבר היררכי: ראש צוות → מושב → פק. מסירה בין פקים חייבת ארטיפקט + מה אומת + מה פתוח. «נראה טוב» לא מקדם שלב. המפיק לא השופט היחיד — הסנסור החישובי בלתי תלוי.
