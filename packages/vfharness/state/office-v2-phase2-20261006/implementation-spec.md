# Office v2 Phase 2 implementation spec

## Foundation

1. Close the Candidate Registry import.
2. Freeze lifecycle and exit-verdict semantics.
3. Define admission policy before installation.
4. Define vendor-neutral Golden Fixture contracts and executable evaluator.
5. Define standard resource/cost/security/operations scorecards.
6. Define P0 shortlists as benchmark sets, not winners.
7. Define Pattern Adoption receipts and research freeze/reopen records.
8. Register a critical Phase 2 sensor.

## Exit from foundation work

The Phase 2 sensor must pass, Phase 1 must remain GREEN, policy architecture must accept the new sensor, and the full repository suite must remain green before any candidate bake-off starts.
