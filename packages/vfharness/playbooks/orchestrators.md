# Playbook — orchestrator overlay (no second runtime)

Source list: [andyrewlee/awesome-agent-orchestrators](https://github.com/andyrewlee/awesome-agent-orchestrators) (194, read 2026-08-31).

Embed on `vfe2b` + this harness. Do not install an orchestrator binary, ADE, tmux multiplexer, OpenClaw, or Ralph unattended loop.

## When

User asks to coordinate / משמרת / run several seats / «תזמור» / names the awesome-orchestrators list.

## Do

1. `python3 scripts/vfmem.py who <job>`
2. One job folder. One existing crew (`packages/vfe2b/crews/`).
3. Card must include `מצב` + `דופק` + `אימות` + `ארטיפקט` (`crews/run.md`).
4. Verify before `worker_done` (sensor or named field). Missing → `escalation`.
5. Sale ₪ → `decision_gate` for the lead seat. HQ sends Gmail/IG via tools (`constitution/SEND.md`).
6. Two retries then `packages/vfharness/templates/escalation.md`. Checkpoint under `state/`.

## Do not

Install `amux`, `orca`, OpenClaw, a swarm, or a Telegram/WhatsApp bot.  
Fan-out ₪ or send. Invent Insights. Claim the IG feed posted without a publish tool.
