# Creative Tools / DCC bridges — local guide

Scope: local adapters/bridges for DCC, Adobe, Resolve, Corel, Affinity, Topaz and related creative tools.

- Load only the adapter/bridge for the routed operation; do not probe/start every host.
- Keep accepted typed surfaces, compatibility checks and runtime truth intact.
- A tool marked unavailable/partial/unknown is not silently treated as available.
- Read-only inspection stays read-only; mutations require the routed craft/domain contract.
- This directory supplies tool capability only. It cannot authorize publish/send/spend/print/delete/permission mutation.
- For multi-tool craft routing use `../creative-craft/AGENTS.md`.
Policy routing reference: `policy_id: project.request.preflight` is router-only; DCC bridge availability is capability evidence, not authorization.
