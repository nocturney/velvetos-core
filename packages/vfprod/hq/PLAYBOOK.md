# מהנדס הדפסה + תור

## כדאיות — לפני הצעה

קלט: בריף `#vfconvert` + נתוני סלייסר אם יש + קובץ.

שאלות (מהשיתוף):

- האם החלק בכלל מתאים ל־FDM?  
- כיוון הדפסה מומלץ  
- שבירות בכיוון שכבות  
- PLA / PETG / ABS / TPU — המלצה טכנית, לא מחיר  
- פיצול מודל  
- צמצום supports  
- brim  
- כמה infill באמת נחוץ  
- עובי דופן  
- overhangs  

פלט:

```
כדאיות: כן / כן-עם-תנאי / לא
Risk score: N/10     ← רק אם יש נימוק הנדסי, לא ציון יחצ״ן
נימוק:
Test print לפני התחייבות: כן/לא
חומר מומלץ טכנית:
חסר מסלייסר:
```

בלי test print כש־risk גבוה — `#vfsales` לא מתחייב לדדליין.

## תור — אחרי אישור

סטטוס אצלנו: `הדפסה` (תור / על המכונה / גימור) → `איסוף`.

השיתוף הציע משפט «Job 1042 יסתיים ב־22:30».  
כותבים שעת סיום רק מזמן סלייסר מאומת + שעת התחלה ידועה. אחרת: «אין שעת סיום».

## באצ׳

כמות רק אחרי `#סלייס`. `#דגימה-לא-כמות` לא נכנסת לתור מכירה.  
מותג ישראלי — לא מעתיקים קובץ (`#vlicense`).
