## כלל

חום / חוזק / כושר נשיאה מופיעים בפיד **רק** אם יש:

1. שורה מאומתת כאן, או
2. מבחן מתועד (`test_protocol` + תוצאה), או
3. גיליון יצרן שראש צוות שם בכרטיס.

אחרת: משמיטים את השדה. לא כותבים «עד 75°C» מהאוויר.

```json
{
  "material": "PETG",
  "claim": null,
  "source": "חסר",
  "note": "נתונים תפעוליים להמחשה; התאמה לשימוש הסופי נבדקת לפי דרישת הפרויקט."
}
```
