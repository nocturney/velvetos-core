# Charts — ויזואליזציית מספרים לבריף / קונסולה

מקור: [larashero3-dotcom/lieflat-charts](https://github.com/larashero3-dotcom/lieflat-charts) (Agent Skill · HTML charts).  
**דפוסים בלבד.** אין `npx skills add`, אין ייבוא gallery/templates מהריפו.

משלים: `DIAGRAM-MAKER.md` = **זרימות/מבנה** (SVG). כאן = **מספרים שנמדדו** (חריץ 06 / portlets).

## מתי

- חריץ **06 מה קורה בעמוד** — רק Insights מאומתים / snapshot בעלים.
- דוח פנימי (cash pulse / weekly revenue) כשיש מספרים ממקור — לא בגייל כ־SVG.
- קונסולה פנימית עתידית — Glance לסיכום מהיר.

**לא** במייל תצוגה 3 כברירת מחדל (Gmail לא אמין ל־HTML charts מורכב). המייל נשאר טבלאות (`MAIL.html`). Chart = לוויין HTML / Drive / ארטיפקט.

## חוקים קשיחים (מותאמים ל־VF)

1. **מספר בלי מקור = אין גרף.** כותבים «אין ספירה» — לא אפס ירוק, לא המצאת Insights.
2. **תרשים אחד = מסקנה אחת.** כותרת = מסקנה («איפה ירדנו»), לא שם סוג הגרף.
3. **צורת נתון → סוג גרף** — קודם מסתכלים על הנתונים (השוואה / זמן / חלק מכלל), לא שואלים «רוצה עוגה?».
4. **יחידות אמיתיות** בכותרת משנה / מקור; תאריך snapshot חובה.
5. **Mono / טוקני `DESIGN.md`** — לא סגול SaaS, לא glow, לא צבעי מותג מומצאים ל־IG.
6. **כמות גרפים** לפי מספר מסקנות עצמאיות (1 שאלה → 1 גרף; 2–3 מסקנות → עד 3). לא לfilling.
