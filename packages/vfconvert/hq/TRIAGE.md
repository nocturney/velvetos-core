# Triage — מיון לפני עומק

מקור דפוס: [mattpocock/skills `triage`](https://github.com/mattpocock/skills) (LinklyAI/best-skills 2026-09-07).  
**לא** `npx skills`. דפוס על `vfconvert` בלבד.

## מתי

לפני grill / הצעה / ריצה ארוכה — כשיש כמה פניות או כמה שדות פתוחים.

## שלוש דליים (בלי ₪)

| דלי | קריטריון | פעולה |
|---|---|---|
| **עכשיו** | יש חומר+כמות+קובץ או שרשור חי שמחכה | `GRILL.md` → כרטיס + `חסר:` |
| **המתנה** | חסר אדם בוואטסאפ / אישור ראש צוות / סלייס | שורה בבריף `02` · לא ממציאים |
| **ארכיון** | ספאם / מחוץ למנדט (משלוח ארצי, אוטו־DM) | דולג · לא פק חדש |

## פלט

שורת triage אחת לכרטיס:

```
triage: עכשיו|המתנה|ארכיון · חסר: <שדות או «אין»>
```

## לא

- המצאת מחיר או Insights
- דילוג על grill כשיש יותר משני שדות חסרים בפנייה מורכבת
- שליחה אוטומטית
