# vfmakers — איך מטמיעים

חמישה צוותים. כל צוות הוא נוהל משרד, לא מוצר חדש. מקור הרעיון: [makerskills](https://github.com/coreyhaines31/makerskills). הביצוע: הפאקים שכבר יש.

אם Agency desk כבר ממוזג, אפשר גם `@chief-of-staff` / `@studio-operations` / `@bookkeeper-controller`. הצוותים כאן לא תלויים בזה.

## 1. החלטה — `crews/decide.md`

**מהרשימה:** `decide` (37signals, 6–8 שאלות, ארכיון + תאריך חזרה).

**אצלנו:**

1. משפט אחד: בין מה למה. סיכון / הפיכות / דדליין.
2. תמיד: האם בכלל צריך להחליט, האם זה ראש צוות, אינסטינקט ראשון, הפיכות, מה נעקור אם נגיד כן.
3. ₪ / B2B / בוסט / טיקטוק → רק ראש צוות. אחרת: «אדם לא נכון».
4. קריאה ברורה: מחליטים / מחכים / לא מחליטים / מחליטים קטן יותר. בלי «אולי».
5. ארכיון ב־`packages/vfbiz/hq/decisions/`. אין ₪ ממולא.

## 2. קיר — `crews/unstuck.md`

**מהרשימה:** `unstuck` (סיווג + 10 זוויות לפני שיפוט).

**אצלנו:**

1. מפרקים את המילה «אי אפשר»: יקר / נעול ברישיון / הלקוח אמר לא / אין סלייסר / הנחה.
2. קיר פיזיקה (FDM לא עושה את הגיאומטריה) = יציאה כנה + שינוי מטרה.
3. «לא» של לקוח או רישיון / מותג ישראלי — לא עוקפים. מחפשים דלת אחרת שהם יפתחו.
4. 2+ זוויות סותרות → `decide`.
5. ארכיון ב־`packages/vfops/hq/walls/`.

## 3. דופק כסף — `crews/cash-pulse.md`

**מהרשימה:** `company-cfo` (שבועי / חודשי / תרחיש) — בלי בנק חי.

**אצלנו:**

1. מקורות: `vfbooks`, `vfcost`, תווית ג׳ימייל «חשבונות», Invoice4U בנושא. לא Stripe/Plaid.
2. מספר חסר → «אין במקור». אל תמלא.
3. שבועי: יתרה ידועה + חשבוניות נכנסות + חוב פתוח מאומת. בלי תחזית בדויה.
4. חודשי: אותם שדות + מה נפתח בחודש. תרחיש רק עם מספרים שכבר כתובים.
5. ארכיון ב־`packages/vfbooks/hq/pulse/`. לא שולחים תזכורת ללקוח.

## 4. רוטציית תוכן — `crews/content-rotation.md`

**מהרשימה:** `jab-hook` (ג׳אב־ג׳אב־ג׳אב־הוק) — בלי Typefully / X.

**אצלנו:**

1. ג׳אב = ערך / רצפה / איך מדפיסים. הוק = וואטסאפ `050-2517000` / איסוף שדרות.
2. לא שני הוקים ברצף. לא «שלחו DM». לא בוסט.
3. `vfcopy` → `vfcovers` / Canva → `vfigos` סקירה. **HQ לא שולח.**
4. Proof מהרצפה בלבד. אין סצנה מומצאת. אין Insights בדויים על הגרפיקה.
5. תוכנית שבוע ב־`packages/vfgrowth/hq/rotation/`.

## 5. מוח סטודיו — `crews/studio-brain.md`

**מהרשימה:** `company-brain` (לכידה + אמון + שאילתה) — בלי כספת שנייה.

**אצלנו:**

1. שפת לקוח → `packages/vfcopy/hq/customer-language.md`.
2. התנגדות מכירה → `packages/vfsales/hq/objections.md`.
3. שאלה שחוזרת → `packages/vfconvert/hq/PLAYBOOK.md` (או הערה בשיחה).
4. כל לכידה: `trust: unreviewed` עד שאדם מאשר. deprecated לא נמחק — מסומן.
5. שאילתה רק מ־HQ. חסר → «חסר». אין דרייב רפואי/משפטי/אישי אלא אם נקב בשם.
