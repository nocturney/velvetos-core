# Crew: unstuck

Source pattern: [makerskills `unstuck`](https://github.com/coreyhaines31/makerskills/blob/main/skills/unstuck/SKILL.md) — wall types + lateral techniques, 10 angles before judging.
Packs: `vfops`, `vfprod`, `vlicense`. Seats: ייצור / ראש צוות.

## Roles

| Role | Pack | Does | Does not |
|---|---|---|---|
| Classifier | `vfops` | Names the wall type without the word «אי אפשר» | Report a naked dead end |
| Floor | `vfprod` | Restates geometry / material / queue facts | Invent slicer hours |
| License | `vlicense` | Holds the file gate | Work around a closed license |
| Human | — | Picks 1–3 angles | — |

## Wall types

| Type | «אי אפשר» usually means | First move |
|---|---|---|
| Assumption | Nobody re-checked | List beliefs vs verified facts |
| Framing | Goal wording hides the door | Restate one level up and one level down |
| Gatekeeper | A person said no | Different door they would open — never the closed one |
| Tool | «הכלי לא תומך» | Substitute the primitive (Canva vs Superdesign, Gmail read vs send) |
| Resource | No time / money / bed | Toggle one constraint; missing ₪ stays `X ₪` |
| Physics | FDM / math actually cannot | Honest exit. Reroute the goal |

## Hard nos (load-bearing — do not crowbar)

- Customer said no and meant it
- File license / Israeli brand copy (`#vlicense`)
- HQ send / auto-DM / national shipping
- Invented sale price

Those are not walls to break. Offer a **different** ask (pickup window, material, qty, finish) on WhatsApp by a human.

## Run

1. Goal (the job, not the blocked step), wall, attempts list, source of the no, stakes + deadline.
2. Decompile «אי אפשר». Two altitudes.
3. Assumption autopsy — always. Mark verified vs inherited.
4. Generate **10 angles, different in kind**, before scoring any.
5. Sort: try now / needs research (`vfresearch`) / wild-30-min / dead (name the real constraint).
6. Commit 1–3 angles with a next action. Mutually exclusive → `crews/decide.md`.
7. Archive `packages/vfops/hq/walls/YYYY-MM-DD-<slug>.md` + `INDEX.md`.

## Agent fast path

If a «that's not possible» sentence is forming mid-task:

1. Classify in one line.
2. Autopsy 3–5 assumptions.
3. Five angles minimum before telling the user; ten if you will report a dead end.
4. Proceed on a viable angle, or attach the inventory. Never a naked dead end.

## Done when

Either a next action exists, or the wall is declared load-bearing with a rerouted goal. No license bypass. No invented queue hours.
