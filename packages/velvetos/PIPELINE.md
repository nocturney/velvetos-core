# צינור אוניברסלי

VelvetOS מחזיק **חמישה שלבים קנוניים**. כל instance ממפה עליהם תוויות בעברית (או שפה אחרת). אין צינור שני.

## שלבים קנוניים

| id | משמעות | דוגמת VF | דוגמת יופי | דוגמת חוות דעת |
|---|---|---|---|---|
| `lead` | פנייה נכנסה | פנייה | פנייה / הודעה | פנייה / הפניה |
| `talk` | בירור / תיאום | שיחה | תיאום תור | איסוף חומר |
| `offer` | הצעה / היקף | הצעה | הצעת מחיר / חבילה | היקף חוות דעת |
| `fulfill` | ביצוע | הדפסה | טיפול / תור | כתיבה + מסירה |
| `close` | סגירה | איסוף | מעקב / סיום | ארכיון / סגירה |

## מיפוי לפקים (תמיד אותם)

| שלב | פקים |
|---|---|
| lead | `vfconvert` |
| talk | `vfconvert` + `vfsales` |
| offer | `vfsales` + `vfcopy` + `vfcost` |
| fulfill | `vfprod` (או מיפוי instance ל־appointment/document) |
| close | `vfsales` follow-up + `vfgrowth` תוכן אחרי הוכחה |


## אספקה (fulfillment.mode)

| mode | מתי |
|---|---|
| `pickup` | לקוח מגיע (VF · שדרות) |
| `appointment` | תור במקום (יופי / קליניקה) |
| `document` | מסירת קובץ/PDF (חוות דעת) |
| `hybrid` | שילוב — רק אם ה־instance מגדיר במפורש |

## כלל

שמות אנגליים מהשיתוף (NEW / QUOTED / PRINT QUEUE…) הם **כינויים** לשלבים — לא צינור נפרד.  
Tenant חדש מוסיף תוויות ב־`pipeline.stages` — לא פק חדש ולא מושב שישי.
