# Fulfillment — appointment

Module id: `fulfill-appointment`

## Provides
Booked calendar slot / chair / station. Close stage = follow-up after the visit.
Used by beauty / service verticals.

## Packs
\`vfops\` (calendar), \`vfprod\`, \`vfsales\`

Always present in core. An instance enables it via `modulesEnabled` — this is not an on/off goal toggle in a shared tenant list.
