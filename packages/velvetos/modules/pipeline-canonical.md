# Canonical pipeline

Module id: `pipeline-canonical`

## Provides
Stages: \`lead → talk → offer → fulfill → close\`.
Instance supplies Hebrew (or other) labels only — never a second pipeline.

## Packs
\`vfconvert\`, \`vfsales\`, \`vfprod\` (+ close follow-up)

Always present in core. An instance enables it via `modulesEnabled` — this is not an on/off goal toggle in a shared tenant list.
