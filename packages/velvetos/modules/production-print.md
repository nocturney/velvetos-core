# Production — print

Module id: `production-print`

## Provides
3D-print floor workflow: feasibility, queue, SKU, license. No print job from HQ agents.

## Packs
\`vfprod\`, \`vfsku\`, \`vlicense\`

Always present in core. An instance enables it via `modulesEnabled` — this is not an on/off goal toggle in a shared tenant list.
