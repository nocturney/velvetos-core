# Crew: reference-plan

Source pattern: OpenMontage «Paste A Video» + `reference_input` on `pipeline_defs/cinematic.yaml`.
Packs: `vfgrowth`, `vfresearch`, `vfcopy`, `vfcanva`.

## Roles

| Role | Pack | Does | Does not |
|---|---|---|---|
| Watcher | `vfgrowth` | Name the reference. Keep / change. | Download a paywalled file |
| Researcher | `vfresearch` | Cite the link the user gave. | Invent a viral Reel |
| Copy | `vfcopy` | Hebrew hook options from the keep-list. | Post |
| Visual | `vfcanva` | Size only (`ig_reel_cover`). | Fake a floor still |
| Human | — | Picks one of 3 variants. | — |

## Run

1. Need a URL or a named local clip. Missing → **חסר**. Stop.
2. Write four lines:
   - **נשמר:** pacing / hook style / structure / tone
   - **משתנה:** our print, Hebrew voice, WhatsApp CTA
   - **מסלול כלים:** floor proof + Canva + `vfigos` → Grok. Not Veo/Kling.
   - **עלות:** if a paid generator is requested, say so and wait for the lead seat. No ₪ figure unless Christian gave one.
3. Offer **3** variants that share the keep-list and differ in angle (timelapse-led / before-after / how-to-order).
4. Stop. Do not generate motion. Do not copy an Israeli brand frame.

## Done when

A one-page plan exists and a human picked a variant. Send status is **not sent from HQ**.
