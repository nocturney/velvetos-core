# שער רישוי וזכויות

מושב: **ייצור**.

## מדיניות בעלים · 2026-10-06

Velvet Factory משתמש בדגמים גם למחקר, הדפסת ניסיון, הוכחת יכולת, תיק עבודות ו-showcase. לכן **רישיון של מודל צד שלישי אינו blocker תפעולי למחקר, slicing, test print, צילום או showcase**.

החריג הקבוע: **יוצר/מותג ישראלי** → עוצרים ומעלים ל-Christian לבדיקה פרטנית לפני שימוש פומבי או מסחרי. לא מחליטים במקומו.

| מצב | פעולה |
|---|---|
| יוצר/מותג לא-ישראלי, כל רישיון/רישיון לא ידוע | ממשיכים למחקר, slice, test print ו-showcase. רושמים source URL/provenance אם זמין; license metadata הוא מידע, לא gate |
| CC BY-NC / NC / ND / Standard Digital File / תנאים לא ברורים | לא חוסמים research/showcase. אם בעתיד נוצרת עסקת מכירה קונקרטית של אותו דגם, זו נקודת החלטה נפרדת ולא סיבה למחוק את המועמד היום |
| יוצר/מותג ישראלי | human_required: בדיקה פרטנית מול Christian לפני שימוש פומבי/מסחרי; מסמנים israeliBrandStop=true עד החלטה |
| מודל מ-3D AI Studio / Meshy / Tripo / מחולל | מותר למחקר/showcase לפי Asset Truth; אין טענה אוטומטית לבעלות על מודל חיצוני |
| MakerWorld / Printables / מקור ציבורי אחר | עצם ההורדה אינה הוכחת בעלות, אבל גם אינה blocker ל-showcase. שומרים URL/מקור כשזמין |
| מכירה עתידית קונקרטית של דגם צד שלישי | בודקים אז את הזכויות הנדרשות לאותה עסקה אם צריך; עד אז אין waiting-license אוטומטי |
| לא ברור אם היוצר ישראלי | שואלים את Christian רק על נקודה זו; לא חוסמים בגלל license metadata כללי |

כללים:
- לא משתמשים בחומר שהושג בפריצה, פיראטיות, עקיפת תשלום/גישה או מקור גנוב.
- תוכן/asset ציבורי שנגיש כדין יכול לשמש למחקר, עבודה פנימית ו-showcase לפי המדיניות לעיל.
- אין לטעון שבעלות או רישיון הוענקו כשלא הוכח כך.
- אם בעתיד נמכור בפועל מוצר שמבוסס על קובץ של צד שלישי, אפשר לפתוח בדיקת עסקה נקודתית במקום להחזיק את כל המערכת חסומה מראש.
- תווית אריזה/זהות נשארת Velvet Factory לפי vfsku/TAG.md; לא מתחזים ליוצר המקור.
