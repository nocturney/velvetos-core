# שער רישיון

מושב: **ייצור**.  
מקור Gemini: Ideation «דגמים ברישיון מתאים».  
מקור Perplexity: Meshy / Tripo (מודל שנוצר, לא קובץ ציבורי).

| מצב | פעולה |
|---|---|
| רישיון בינלאומי ציבורי שמאפשר מכירה | ממשיכים ל־`vfsku` / `vfsales` |
| מותג ישראלי / קובץ שאסור להעתיק | עוצרים. לא מעתיקים |
| מודל מ־Meshy/Tripo / מחולל | לא «ציבורי מסחרי» אוטומטית. ראש צוות מאשר לפני באצ׳ |
| לא ברור | שואלים ראש צוות. לא מנחשים |
