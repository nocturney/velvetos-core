# Revenue Loop — מנוע הכנסה מ-IG

מודול: `expert-revenue-loop`.  
מטרה: **IG כמקור פרנסה** — לא רק תוכן יפה.

## לולאה

```
תוכן (proof + offer)     @offer-lead-gen-strategist + Social Booster
        ↓
פרסום                    @instagram-curator (vfigos/SEND.md)
        ↓
מדידה (24–48ש)           @tracking-measurement-specialist (snapshot)
        ↓
פנייה                    @email-intelligence-engineer → vfconvert
        ↓
הצעה                     @sales-engineer + @deal-strategist
        ↓
מעקב                     @email-marketing-strategist (Gmail)
        ↓
הדפסה / מימוש             @studio-producer
        ↓
איסוף                    אדם (WA + Invoice4U)
        ↓
retention                @customer-success-manager
        ↓
למידה                    owner-memory + Social Booster שבועי
```

## כלל ברזל לפוסט

לפני שיבוץ — כרטיס **Offer**:

| שדה | חובה |
|---|---|
| מק״ט / שירות | `#vfsku` או תיאור מדויק |
| מחיר | מאומת או `X ₪` |
| CTA | וואטסאפ `050-2517000` / איסוף |
| ig_post_ref | מזהה/תאריך לכרטיס pipeline |
| proof | תמונה מהרצפה |

בלי Offer — תוכן מותר כ«מותג» בלבד, לא כמכירה.

## כרטיס pipeline (הרחבה)

על כל job / פנייה מ-IG:

```markdown
- ig_source: post|reel|story|carousel
- ig_post_ref: YYYY-MM-DD / Canva id / caption hook
- offer_sku: …
- stage: פנייה|…
```

ראה `vfops/hq/PIPELINE-BOARD.md`.
