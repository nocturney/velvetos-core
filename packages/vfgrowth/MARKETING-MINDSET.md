# Marketing Mindset — דפוס הטמעה (lite)

מקור: [axelfreeman/marketing-mindset](https://github.com/axelfreeman/marketing-mindset) (`marketing-mindset`, trending LinklyAI 2026-09-09).  
**דפוסים בלבד** — לא `npx skills add`. לא פק חדש.

## מתי

לפני רעיון צמיחה / פוסט שיווקי / «האם כדאי X כדי לקבל Y» / פתיחת ערוץ חדש.  
אחרי `CONTENT-RUBRIC.md` ולפני PREFLIGHT.

## שישה עקרונות (VF)

1. **לא מדוקטרינת LLM / SEO ישן.** מקורות: מתחרים חיים, רצפת סטודיו, בעלים — לא «ספר שיווק 2019».
2. **אופק 3 חודשים.** רעיון בלי תועלת בחלון קצר → דחה או צמצם. אין תוכניות שנתיים מ־HQ.
3. **הבעלים זז ראשון.** HQ לא חוסם ניסוי לגיטימי; כן חוסם אוטו־DM / בוסט / Print.
4. **השערה שניתנת לבדיקה מהר.** צעד אחד שאפשר להריץ השבוע (פוסט / שיחה / מדף) — לא «קמפיין מלא».
5. **שיווק לפני מוצר מלא.** מותר לספר «מה מגיע» על גלם/דגם אמיתי — בלי ₪ / Insights / דדליין מומצאים.
6. **אין עבודה בחינם ללא חילופין.** חילופין = ליד אמיתי / שיחה / איסוף שדרות / למידה מתועדת. לא «לפורטפוליו» בלי מסלול.

## מקורות אמת (סדר)

1. מתחרים שפונים **עכשיו** לאותו קהל ומוכרים (לא מותג ישן בלי נוכחות).
2. חברות צעירות צומחות > מותגים שתקועים עם יח״צ.
3. **סטופ־ליסט:** Product Hunt / טופ־10 / דוחות >6 חודשים / אינפלואנסרים כ־«אמת».
4. רשתות חברתיות — רק אחרי סינון ספאם/בוטים; מדדי `@velvets_cloud` רק מ־Dashboard/CSV.

## ויזואל (עין)

כל פריים Canva/vfcovers: **רקע+סצנה · גיבור אחד · תנועה** (או רמז לתנועה בסטיל).  
בלי קולאז׳ צפוף ובלי טקסט על רצפה גולמית.

## פלט מצופה

- 2–3 מתחרים רלוונטיים (או «אין גוף / אין מקור»)
- השערה אחת + מבחן השבוע
- משימת תוכן אחת ל־`vfcopy` / לוח `vfgrowth` — CTA ציבורי = `PUBLIC_CURRENT_CTA` (הודעת Instagram בעברית · איסוף שדרות). וואטסאפ `050-2517000` = BUSINESS_CONTACT_RECORD בלבד — לא בכיתוב.

## לא

- המצאת Insights / ₪ / טרנד
- אוטו־DM / בוסט / אתר שיווקי ציבורי מ־HQ
- וואטסאפ / `050-2517000` / `wa.me` כ־CTA ציבורי
- התקנת הסקיל החיצוני על Cloud
- קמפיין ממומן בלי ראש צוות
