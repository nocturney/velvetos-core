# Skill scouting sources

This extends the existing `BEST-SKILLS.md` research loop without installing another marketplace or runtime.

## Curated directory

- `ComposioHQ/awesome-claude-skills` — discovery/browse source only. Use it to find candidate skills, then inspect the source and map useful patterns into existing VelvetOS packs.
- `LinklyAI/best-skills` remains the ranked pulse source already used by the office.

## Rules

1. Never install a directory wholesale.
2. Prefer pattern extraction over a second runtime or duplicate pack.
3. Record `embed | watch | skip` with the reason.
4. Security, authority, pricing, publishing, and truth gates remain VelvetOS-owned.
5. If a candidate is already functionally embedded, strengthen or verify the existing implementation instead of duplicating it.
