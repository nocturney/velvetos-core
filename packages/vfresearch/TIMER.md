# Best Skills — on-demand research

**Owner override 2026-10-06:** ה־standing scan של ~48 שעות פרש כחלק מצמצום שכבת התזמון.

סמכות נוכחית: **manual/event-driven research**. There is no timer and no Research Seat clock עבור Best Skills.

מריצים מעבר רק אם כריסטיאן מבקש, אם החלטת tool/skill דורשת מידע עדכני, אם צורך תוכן אמיתי דורש זאת, או אם freeze gate פתוח ב־Office v2 מציין את המחקר הזה.

`packages/vfresearch/BEST-SKILLS.json` שומר `lastPass`, `lastArtifact`, `lastResult` כ־provenance בלבד. Age alone does not create a task, blocker, notification or automation.

## כשמריצים מעבר

1. לקרוא `BEST-SKILLS.md` + `BEST-SKILLS.json`.
2. לקרוא מקור ציבורי עדכני; לא להמציא דירוג.
3. להטמיע רק דפוסים שימושיים ב־packs קיימים.
4. לכתוב `packages/vfresearch/sources/YYYY-MM-DD-best-skills.md`.
5. לעדכן state ולהריץ sensors רלוונטיים.

חזרה לקדנס מחזורי דורשת החלטת בעלים מפורשת חדשה.
