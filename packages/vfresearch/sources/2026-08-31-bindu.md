## מה זה

- `bindufy()` — עוטף handler ומעלה סוכן עם DID, A2A JSON-RPC, mTLS, OAuth2 (Hydra), x402 (USDC).
- Gateway — planner שמתזמר fleet של סוכנים.
- Skills / agent cards — הצהרת יכולות לפני קריאה.
- SDK: Python, TypeScript, Kotlin — gRPC core משותף.

## שאלות המחקר

1. **פק חדש?** — לא. דפוסים בלבד על `vfe2b` + `vfharness` + `vfmem`.
2. **מתקינים?** — לא. `bindufy`, Gateway, swarm, x402 — skip. Cursor הוא המשרד.
3. **מה כבר יש?** — agent cards = `vf-desk.json` + `SKILL.md`; אימות = סנסורים + `decision_gate`; checkpoint = `vfharness/state/`.
4. **x402 / crypto?** — לא רצפת הדפסה. `docs/MCP-FIT.md` כבר נעול.
5. **מתי «later»?** — B2B חיצוני (`vfbiz`) + `@agentic-identity-trust-architect` — negotiation/scoped auth, עדיין בלי USDC.
