# Voice corpus — הפרדת למידה

רק תוכן **מאושר על ידי אדם** או **פורסם** משמש קורפוס קול אמין.

| תיקייה | סטטוס | מותר ללמוד ממנו |
|---|---|---|
| `approved/` | published / human-approved | כן |
| `generated/` | AI draft / unapproved | **לא** |

אל תעתיקו טיוטות מ־`generated/` ל־`approved/` בלי אישור אדם.  
אל תלמדו אוטומטית מטיוטות AI.
