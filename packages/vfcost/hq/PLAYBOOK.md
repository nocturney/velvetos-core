# גיליון עלות — לא מחירון

השיתוף ביקש סוכן שמחזיר שורות ₪. כאן השורות קיימות; הסכומים ריקים עד קלט מאומת.

## קלט חובה

| שדה | מקור מאומת |
|---|---|
| חומר (PLA / PETG / …) | סלייסר / מלאי |
| גרמים | סלייסר |
| שעות הדפסה | סלייסר |
| דקות עבודה ידנית | רצפה / אומדן אדם, מסומן כאומדן |
| גימור | בריף `#vfconvert` |
| סוג לקוח | פרטי / B2B נעול |

בלי סלייסר — עוצרים. `#סלייס` חסר.

## פלט

```
עלות חומר:     X ₪
עלות מכונה:    X ₪
עבודה:         X ₪
רזרבה לכשל:    X ₪
עלות כוללת:    X ₪
מחיר מינימום:  X ₪   ← רק אחרי נוסחה + סכום שאושר
מחיר מומלץ:    X ₪   ← לא ממציאים
מחיר פרימיום:  X ₪   ← לא ממציאים
רצפה: לא לרדת מתחת ל־X ₪ (ריק עד אישור)
```

נוסחה נרשמת במילים («גרם × מחיר ק״ג מאומת ÷ 1000») בלי להמציא מחיר ק״ג.  
אם יש מחיר ק״ג מאומת במלאי — משתמשים בו ומציינים את המקור.  
עלות חומר ≠ מחיר מכירה.

## מסירה

`#vfsales` מקבל את הגיליון. הסטודיו לא שולח הצעה עם `X ₪` בלי להגיד ללקוח שחסר סכום — עדיף לא לשלוח עד `#מחיר-מכריסטיאן`.

B2B נעול (`#vfbiz`) לא מקבל מחירון חדש מכאן.
