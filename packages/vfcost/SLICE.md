# סלייס בלי מחיר מכירה

מושב: **ייצור**.  
מקור Gemini: STL Quote (משקל וזמן) + Material Tracker.  
מקור Perplexity: Spoolworth (חשמל + רווח) · STLforge (תיקון) · PrintPal (שכבה/מילוי/תמיכות).

## לפני סלייס

אם הקובץ פגום (Non-manifold ודומיהם): לתקן בכלי שיש בסטודיו, לרשום «תוקן», ואז לסלייס.  
HQ לא מריץ סוכן תיקון בענן ולא ממציא גיאומטריה.

## אחרי סלייס

רושמים רק מה שהסלייסר פלט:

| שדה | מקור | לא |
|---|---|---|
| גרם | סלייסר | ניחוש |
| דקות | סלייסר | ניחוש |
| חומר | מה שעל המדפסת / מה שאישר ראש צוות | שדרוג מומצא |
| גובה שכבה / מילוי / תמיכות | מה שהסלייסר הראה | ייעוץ PrintPal מומצא |
| עלות חומר | רק אם יש מחיר ק״ג **מאומת** במלאי | מחיר מכירה לקליקר |
| חשמל | רק אם ראש צוות נתן תעריף חשמל מאומת | ניחוש ₪ · תוספת רווח |

עלות חומר ≠ מחיר מכירה. תוספת רווח היא החלטת ראש צוות, לא נוסחה מהמשרד.  
באצ׳ למכירה רק אחרי סכום מראש צוות.
