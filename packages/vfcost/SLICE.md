# סלייס בלי מחיר מכירה

מושב: **ייצור**. מקור Gemini: STL Quote (משקל וזמן) + Material Tracker (צריכה).

רושמים רק מה שהסלייסר פלט:

| שדה | מקור | לא |
|---|---|---|
| גרם | סלייסר | ניחוש |
| דקות | סלייסר | ניחוש |
| חומר | מה שעל המדפסת / מה שאישר ראש צוות | שדרוג מומצא |
| עלות חומר | רק אם יש מחיר ק״ג **מאומת** במלאי | מחיר מכירה לקליקר |

עלות חומר ≠ מחיר מכירה. באצ׳ למכירה רק אחרי סכום מראש צוות.
