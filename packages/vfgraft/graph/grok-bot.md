# grok-bot

## Summary

Grok Bot holds the five live seats: Instagram send, Gmail send, and printers. This HQ drafts, reviews, and schedules. It does not press Send, boost, or auto-DM. Chat on Grok is decisions only.

When Grok weekly quota is exhausted: HQ keeps producing (`vfharness` playbook). Non-urgent posts stack in `vfigos/QUEUE.md` as `#מוכן-ל-Grok`. Urgent live posts use `#פרסום-חי-דחוף` + `LIVE-PACKET.md` — a **human** publishes; the HQ agent still does not press Publish.
