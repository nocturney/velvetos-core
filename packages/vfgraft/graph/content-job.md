# content-job

## Summary

Velvet Factory content is an exception-only autonomous Visual Foundry pipeline over existing packs. Floor proof / verified media first; no invented scenes. `expert-media-director` runs opportunity qualification → Asset Truth/Claim Provenance → Content Contract → proof-first Creative Director → progressive variants → Evaluation Engine → targeted repair → render/derivatives → Exception Queue → publish authorization → `vfigos` tool send/verification → evidence-backed learning.

Routine creative choices do **not** require owner review. Physical footage/staging, unclear rights/privacy, unsupported high-stakes claims, ₪/spend/Boost, customer WhatsApp, Print from HQ, irreversible actions or a hard blocker after failover remain human gates.

## State

Canonical Foundry progression:

`discovered → qualified → contracted → concepted → storyboarded → media_ready → rough_generated → visually_scored → repaired → rendered → authorized_for_tool_publish → published_verified → performance_learned`

Terminal/side outcomes:

`archived | waiting_for_media | ready_for_publish | human_required`

The office control plane remains the runtime/state authority. `FOUNDRY.json` is policy/configuration, not a second queue or database.

Velvet Factory instance may set `creativeAutonomy.publish.standingAuthorization=true`. This is a standing owner authorization for LOW-risk routine organic Instagram only; it is not permission for auto-DM, Boost/Ads, price changes, unsupported claims, customer WhatsApp or Print.

## Truth contract

Media Vault remains the canonical asset source. An optional `truth` block on a media item records asset origin/truth level/rights/use. Missing `truth` is treated as `unverified` for public factual claims.

Every public factual content job must build a Content Contract. `truthClaims[].status=verified` requires real evidence refs; a real asset by itself does not prove every claim. `illustrative_ai`/`synthetic` may support composition but never prove a physical measurement, load, failure or success.

## Variant + QA contract

Use progressive commitment instead of many expensive final renders: concepts → storyboard/mock previews → rough cuts → at most two final renders by default. Evaluate with deterministic checks + perceptual rubrics + reference fidelity + artifact checks, then run bounded targeted repair.

Novelty/fatigue checks use existing office-learning/vfinsights history, not a second creative memory store. Similarity can trigger a mechanic change, cooldown or explicit series override.

Media Vault remains canonical and `vfigos` remains the Instagram publish/verification path. No publish claim without a real tool receipt + verification evidence. No tool = honest failover packet. Grok remains optional backup/failover, not the primary sender.
