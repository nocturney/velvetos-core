# vfgraft locks

Graft the product stays off this HQ. Graft the pattern (committed markdown graph) is what we keep.

## npm / MCP — דלג

`npm install -g @nanonets/graft`, `npx @nanonets/graft init`, `graft mcp`, `.cursor/rules/graft.mdc` from the installer, `graft/` as a gitignored cache.

למה:

1. Graft tree-sitter מדלג על Markdown. כמעט כל ה-HQ הוא Markdown.
2. `graft build --deep` דורש מפתח ספק. אין חשבון מודל שני מ-HQ.
3. הגרף של ה-CLI הוא מטמון מקומי (כמו `node_modules`). הוא לא משותף בין סוכנים.
4. `vfe2b` כבר נועל סוכן-קידוד שני. Cursor הוא המשרד.

## טלמטריה / מפתח — דלג

`GRAFT_API_KEY`, `OPENROUTER_API_KEY`, usage ping. אין סודות בגיט.

## גרף קוד חי — אחר כך (לא עכשיו)

אם HQ יהפוך לעץ TypeScript/Python אמיתי (לא משרד Markdown), ראש צוות יכול לפתוח `graft init --agents cursor --no-mcp`. עד אז המפה ב-`packages/vfgraft/` היא הגרף.
