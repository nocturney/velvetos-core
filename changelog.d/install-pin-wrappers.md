- 2026-10-18 - **Install-pin wrappers:** `scripts/check-install-pins.py` refuses a floating install wrapped in `sudo -H`, `env`, `bash -c`, `sh -c`, a subshell, `$(...)`, or `python -I -m pip`. It also refuses an unpinned `uv pip`, `uv add`, `pipx`, `yarn`, `pnpm`, or `npx` spec. Each pattern is load-bearing: turning it off lets its fixture through, and a bare `pip install` stays caught. `requirements-google-clients.py311.lock` must match the direct pins in `requirements-google-clients.txt`, and every lock pin must have a sha256 hash. Dropping either lock check lets only that drift through. `INSTALL_SPEC_ALLOWLIST` stays empty. `security_admission` stays RED.
