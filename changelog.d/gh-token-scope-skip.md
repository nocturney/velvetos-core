- 2026-10-18 - **GH token scope:** The check-all job token is contents: read, and checkout does not persist it. `GH_TOKEN` is forwarded only to `check-policy-architecture.py`, and that sensor forwards it only to the shadow-observation self-test that runs `gh`. The commit-status write stays on a separate job. A machine precheck fetches `origin/main` with a masked `AUTHORIZATION: basic` header of base64(`x-access-token:<token>`). When gh is offline or unauthenticated, that self-test prints a loud `SKIP_GH_UNAVAILABLE` and the local suite stays green. A missing `git` on `gh`'s PATH is not that skip. Hosted CI still requires the live read to succeed. `security_admission` stays RED.
