- 2026-10-18 - **Per-PR changelog fragments:** capability changes add `changelog.d/<slug>.md` instead of editing `CHANGELOG.md`. `scripts/changelog-compile.py` folds those fragments under Unreleased when someone runs it. The fold is manual and is not a scheduled workflow. The fragment gate accepts a fragment-only diff and rejects a capability diff with neither a fragment nor a `CHANGELOG.md` edit. `CHANGELOG.md` keeps Git's built-in `merge=union` driver as a fallback for direct edits. Released history is not rewritten. No model call.
