- 2026-10-18 - **Spawn home on D:** On Windows the controlled home and temp are created under `%VELVETOS_RUNTIME_ROOT%\spawn-home`, and only when that root is an absolute path on drive D: with no junction. Creation sets the owner to the current user SID and a protected owner-only DACL, including when the elevated default owner would have been Administrators. An unset root, another drive, a reparse point, or a base that is not owner-only write is refused. POSIX still requires a root-owned sticky base and an owner-only private directory. The process removes its home at exit and prunes its own stale spawn directories without following symlinks. An empty caption directory beside a render output is still removed when that runtime root is set. The runtime root's own tmp directory is left in place.
