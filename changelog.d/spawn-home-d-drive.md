- 2026-10-18 - **Spawn home on D:** On Windows the controlled home and temp are created under `%VELVETOS_RUNTIME_ROOT%\spawn-home`, and only when that root is an absolute path on drive D: with no junction. An unset root, another drive, a reparse point, or a base that is not owner-only write is refused. POSIX still requires a root-owned sticky base and an owner-only private directory. The process removes its home at exit and prunes its own stale spawn directories without following symlinks.
