- 2026-10-18 - **Fragment delete is not coverage:** The changelog gate counts only an added or modified `changelog.d` fragment that has a valid non-empty bullet. Status `D`, or a fragment emptied to whitespace, does not cover a capability change. Deleting an existing fragment is refused unless the pull request is the compile step: the diff is only `CHANGELOG.md` plus those deletions, and each deleted bullet is in `CHANGELOG.md`. `security_admission` stays RED.
