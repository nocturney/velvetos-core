- 2026-10-23 - **Sensors enforce OpenPost absence:** `check-openpost-status` and `check-grok-boot-hardening` fail if an obsolete OpenPost runner, failover file or scheduled hook reappears. `check-public-path-redaction` no longer lists the removed failover files.
