# דק שבועי — GitHub Pages

`index.html` הוא הדק העדכני ביותר (נבנה ע"י `scripts/vf_weekly_deck.py`).  
כל קובץ מתויג בתאריך (`YYYY-MM-DD.html`) נשאר בהיסטוריה.  
דרוש הפעלה חד-פעמית: Settings → Pages → Source = `main` / `/docs`.  
כתובת קבועה לאחר ההפעלה: `https://nocturney.github.io/velvetos-core/weekly-deck/`.
