## Immediately reusable patterns

- **Pixel-art composition Skill:** Write a constrained palette/source plan; isolate sprite variants and verify exact pixel bounds, symmetry, transparency, and resulting image before acceptance. The staged Skill describes the optional upstream pxl command only when a pinned local runtime is present and authorized.
- **Research experiment discipline:** Apply baseline, bounded peer branches, numerical or fixture-based evaluator, provenance, explicit negative controls, generation close and retained winner/failed controls to the current harness. This is an independent approach inspired by Praxist, **not a copy of its code or license**.
- **Agent sandbox threat model:** Network-off by default is not the same as host isolation. Test host mounts, allowed paths, forwarding, process lifetime, secrets, snapshot rollback and restore artifacts before trusting any Quicksand-like adapter.
- **Kokon design route:** Creative Craft may *plan* a local generative edit but cannot claim a tool is usable or launch a GPU run until it is admitted through the existing LAB route and readback.
