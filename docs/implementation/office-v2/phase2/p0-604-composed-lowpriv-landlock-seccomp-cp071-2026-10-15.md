The launcher uses privileged `unshare` **only inside this pre-existing disposable Linux guest**; this is not a persistent dedicated worker principal.

Landlock ABI4 then limited filesystem reading/execution to `/usr`, read-write/create inside one random disposable scratch directory and access to `/dev/null`, denied reads and writes to that outside file and `/proc/version`.
