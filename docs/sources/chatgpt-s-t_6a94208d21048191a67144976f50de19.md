## שישה ראשונים

1. תמחור והצעות מחיר — חומר, משקל, זמן הדפסה, חשמל, בלאי, מידול, גימור, רווח. פלט כשורות עלות / מינימום / מומלץ / פרימיום. אזהרה: לא לחשב רק גרמים × חומר.  
2. קליטת לקוח — שאלות קבועות, בריף הזמנה מסודר במקום 25 הודעות.  
3. בדיקת כדאיות / מהנדס הדפסה — FDM, כיוון, שכבות, חומר, פיצול, supports, brim, infill, דופן, overhangs, ציון סיכון, test print לפני התחייבות.  
4. מכירות WhatsApp/Instagram — טיוטות שמובילות לשלב הבא, לא «נשמח לעמוד לשירותך».  
5. תוכן ושיווק — כל עבודה → Reel / Story / פוסט / לפני־אחרי / CTA.  
6. ניהול הזמנות — סטטוסים, דדליין, תשלום, הדפסה, גימור, איסוף. בוקר: איחורים, ממתינים לאישור, מוכנים להדפסה, שעות תור.

## ארבעה אחר כך

מוצרים חדשים (חזרות), B2B, מעקב אחרי מכירה, CFO קטן.

## מעל כולם

Velvet Factory Manager — מריץ שרשרת: קליטה → מהנדס → תמחור → מכירה → ייצור → תוכן → מעקב.
