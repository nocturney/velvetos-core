## 1. קליטה

1. משתמש מעלה ל־**נכנס** — בלי חובת שינוי שם / מיון / טופס.
2. לפני «חסר חומר» — חפש במאגר לפי משימה ותיאור (`search_files`).
3. **מנהל קליטה אחד** בלבד מעביר נכנס→מקור. שאר הכלים לא מריצים קליטה מתחרה.
4. אחרי אימות נגישות + רישום בקטלוג המרכזי → העבר ל־**מקור** (`update_file` parentId). שמור fileId + שם מקורי. אל תמחק / תדרוס מקור.
5. קובץ שלא ניתן לבדוק נשאר ב־**נכנס** עם דיווח חסימה.
6. כפילות = אותו **fileId** בלבד. שם זהה ≠ כפילות. העלאה חוזרת לא יוצרת משימה כפולה לאותו fileId.

מינוי מנהל קליטה: שדה `intakeManager` ב־`packages/vfigos/media-catalog.json`. אם `null` — אין קליטה אוטומטית; דווח לראש צוות.

## 2. קטלוג ותיאום

קטלוג **אחד**: `packages/vfigos/media-catalog.json`.  
אל תיצור קטלוג מקביל לכל כלי / פק / סוכן.

רישום חובה לכל פריט מקור/תוצר:

- `sourceFileId` + `viewUrl`
- `description` מבוסס צפייה (אחרי הורדה/תצוגה)
- `uploadedAt`
- `productSku` רק אם ידוע ממקור מאומת — אחרת `null` (אל תנחש מק״ט / חומר / לקוח / תאריך צילום)
- `status`: `inbox` | `source` | `in_progress` | `approved` | `published` | `blocked`
- `assignee` (מי מטפל במשימה)
- `derivativeIds[]`
- `sourceIds[]` (לתוצר)
- `approvedVersion` (רק אחרי אישור מתועד)

לפני עריכה: בדוק `assignee` בקטלוג — אל תחליף עדכון של כלי אחר.

## 3. עריכה ותוצרים

1. עבוד על **עותק** (`copy_file`) — שמור תוצרים ב־**בעבודה**.
2. שם תוצר: `{taskId}_{kind}_v{N}_{tool}` (למשל `G006_feed_v1_canva`).
3. קשר בקטלוג לכל מקורות ששימשו.
4. Canva: שמור `editUrl` אמיתי **ו** קובץ ייצוא כשהיכולת זמינה (`export-design` / Drive upload).
5. אמת שהקובץ שנפתח נמצא בתיקייה הנכונה לפני «הושלם».
6. שמור גרסאות קודמות. שינוי בתוצר מאושר = גרסה חדשה שדורשת אישור מחדש.

## 4. אישור ופרסום

- העלאה למאגר **אינה** אישור לפרסום.
- העבר ל־**מאושר לפרסום** רק גרסה עם אישור מתועד לפי מסלול VelvetOS (PREFLIGHT / ראש צוות / Decision Pack). מיקום בתיקייה לבד ≠ אישור.
- כלי פרסום משתמש בגרסה המדויקת + כיתוב מאושר. בדוק שהכלי מקבל את **קובץ המדיה** בפועל — קישור שיתוף Drive ≠ קישור הורדה מתאים בהכרח; העדף `download_file_content` או export.
- לפני פרסום: אין פרסום מתועד לאותה משימה. ניסיון לא ברור → בדוק מצב לפני ניסיון חוזר.
- סמן `published` רק אחרי אישור הצלחה מכלי הפרסום + מזהה/קישור פוסט + מועד. הכנה / תזמון ≠ פורסם.
- מסלול שליחה: `constitution/SEND.md` · `packages/vfigos/SEND.md`.
