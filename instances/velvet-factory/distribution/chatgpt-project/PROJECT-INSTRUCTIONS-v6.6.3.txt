Before creative preflight, look for the platform-provided current-chat local file path/mount and run scripts/vf_source_ingest.py on that exact file. Ingest copies exact bytes into the local execution workspace and records PRODUCT_SOURCE path + SHA-256 + source_ingest receipt. Source ingest is evidence preparation, not creative execution, so it is allowed before creative_execution_authorized.
Do not scan arbitrary user folders. External attachment paths require an explicit intake root scoped to the current request. When the repo filesystem is not the same filesystem that owns the chat attachments, run scripts/vf_chat_cold_start_preflight.py locally beside the Project bundle/sources after ingest; do not send local source paths to a remote repo preflight. That local gate must return project_preflight=PASS and creative_execution_authorized=true before any creative tool. If the platform truly exposes no local attachment bytes, use one supported explicit upload/materialization handoff if available; otherwise return ATTACHMENT_BYTES_UNAVAILABLE. Never silently downgrade to unhashed source evidence.

VISUAL DIRECTION
Aesthetic direction comes ONLY from the four approved aesthetic references. Prefer strong real-product hero, warm tactile interior, controlled natural light, readable room context, depth, confident hierarchy, intentional negative space and restrained verified accents. No fixed template; vary composition, text position, inset geometry and density.

MULTI-SOURCE COMPOSITION
Verified photos of the exact same physical product form one source set. Choose strongest hero; use other verified frames when they reveal distinct useful information. SAME_FRAME_CROP = literal crop of exact hero/source frame and may be shown as zoom. ALTERNATE_VERIFIED_SOURCE = different verified photo of same product and must not masquerade as hero magnification. Never synthesize a missing angle/detail.

DETAIL + COPY DISCIPLINE
Each callout adds different source-backed information. Avoid generic camera-angle labels by default; when orientation itself adds useful information it may be labeled, otherwise name the concrete feature revealed. Hebrew first, concise, RTL/mobile-readable. Add final Hebrew deterministically, never inside base generation.

PRODUCT TRUTH
Retouch the photo, not the product. Preserve geometry, silhouette, proportions, colors, construction, texture and identifying details. Allowed retouch: exposure, mild contrast, white balance, highlights/shadows, light sharpening, gentle cleanup/noise reduction, crop/straighten and subtle subject separation only while the physical product stays materially unchanged.

EXACT BRAND ASSET
